# Отчёт об изменениях — 3 ноября 2026

## Результат

Добавлена админ-панель `/admin` в существующий FastAPI-проект. Сайт и генератор используют общие данные SQLite. Исходная таблица преподавателей, их ID и назначения сохранены. В базе: 46 преподавателей, 25 групп, 24 предмета, 300 строк нагрузки, 1 календарь.

## Что можно делать в админке

- Преподаватели: создание, редактирование, удаление неиспользуемых записей; ФИО, годовой лимит, ставка, дневной максимум, методические дни через флажки.
- Группы: создание, редактирование, удаление, курс и специальность.
- Предметы: создание, редактирование, удаление; корпуса пока справочные.
- Учебная нагрузка: назначение преподавателя на группу и предмет через выпадающие списки, число пар A/B; редактирование и удаление строк.
- Календарь: недели A/B, длительность и коэффициент учётных часов за пару.
- Поиск записей в каждом разделе.
- Проверка всех назначений: годовые часы/лимит по каждому преподавателю, вместимость рабочих недель, диапазон 15–20 пар у групп.
- Защита удаления: нельзя удалить преподавателя, группу или предмет, на которые ссылается нагрузка.

Проверки перед сохранением не требуют, чтобы весь учебный план уже был завершён. Можно постепенно вводить данные, затем исправлять сообщения общей проверки. Изменение данных влияет на следующую генерацию.

## Проверки

Автоматические тесты: **10 passed**. Используется временная копия базы, а не рабочая БД.

Проверены:

1. Отказ без авторизации и при неверном пароле, доступ с правильным.
2. Сохранение методических дней и годового лимита; отклонение недопустимого дня.
3. Защита прежнего PUT преподавателей от записи без входа.
4. Блокировка генерации при превышении годового лимита.
5. Создание/удаление группы и преподавателя; сохранённые записи видны публичному API.
6. Запрет удаления используемой группы и назначения отсутствующей группы.
7. Отклонение пустого календаря и сохранение допустимых недель.
8. Отсутствие повторного импорта намеренно очищенного раздела.
9. Генерация 25 групп / 784 занятий, 250 комбинаций «группа + неделя + день», по 3–4 пары.
10. Проверки MOVE/SWAP и корректного результата при отсутствии улучшений.

Дополнительно: все Python-файлы компилируются; Ruff F/I — без ошибок; `node --check` для обоих JS-файлов — без ошибок; проверены уникальность HTML ID и соответствие статических JS-селекторов элементам страниц.

## Что осталось за рамками

- Реальные недели, коэффициент часов за пару и лимиты должен подтвердить колледж. В исходных файлах тестовые данные.
- В годовом расчёте учитывается только нагрузка, введённая в этот план. Внешние занятия и прочие обязанности автоматически не добавляются.
- Корпуса сохраняются как справочные данные; переходы и физкультура по корпусам пока не ограничивают генератор.
- Одиночные пары преподавателей остаются мягким штрафом; их вес не увеличивался.
- Методический день задаётся вручную и не назначается автоматически.
- Авторизация рассчитана на одного администратора: нет ролей, журнала изменений, восстановления пароля по почте и полноценного управления пользователями. Пароль меняется через `setup_admin.py`.
- Работа с CSV массовым импортом через браузер не добавлена: редактирование выполняется формами; первоначальный импорт — `init_db.py`.
- Оптимизация синхронная; фоновые очереди и ускорение намеренно не вводились.
- SQLite подходит для текущего локального сценария. Для публичного сервера нужны HTTPS и эксплуатационная настройка.

## Как применить

Не смешивайте файлы разных версий. Сохраните старую папку, распакуйте новый архив отдельно и следуйте README. База из вашего архива уже включена с импортированными наборами данных. Выполните `python init_db.py`, затем `python setup_admin.py`, запустите Uvicorn и откройте `/admin`.
